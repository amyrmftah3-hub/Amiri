# AMIRI Android

نسخه اندرویدی بازی AMIRI. سورس اصلی در `AMIRI-Android-Source.zip` قرار دارد.

برای ساخت APK از بخش Actions گردش‌کار **Build AMIRI APK** را اجرا کن. فایل `app-debug.apk` در Artifacts با نام `AMIRI-debug-apk` قرار می‌گیرد.

این نسخه آفلاین است؛ ورود امن گوگل، همگام‌سازی ابری و ایردراپ واقعی هنوز فعال نیستند.
