# AMIRI Android

نسخه اندرویدی بازی AMIRI. سورس اصلی در `AMIRI-Android-Source.zip` قرار دارد.

برای ساخت APK، گردش‌کار **Build AMIRI APK** با تغییر سورس یا README اجرا می‌شود. فایل `app-debug.apk` در Artifacts با نام `AMIRI-debug-apk` قرار می‌گیرد. این APK نسخهٔ debug است و برای انتشار عمومی باید جداگانه با کلید امضای release امضا شود.

این نسخه آفلاین است؛ ورود امن گوگل، همگام‌سازی ابری و ایردراپ واقعی هنوز فعال نیستند.
